Google Drive Integration

Setup Required

Configure Google API Key or Service Account to sync and stream media

Ideal for public/shared Google Drive folders. Make sure folder sharing is set to "Anyone with the link can view".

How to generate a free API Key (under 2 mins): Console
  1. Open Google Cloud Console and create or select a project.
  2. Go to APIs & Services > Library, search Google Drive API, and click Enable.
  3. Go to APIs & Services > Credentials, click + Create Credentials > API key.
  4. Copy your key, paste it in the field above, and click Test Connection!

For private Google Drives. Share your Drive folder with the Service Account's client_email.

Paste your shared folder URL or ID. Folder must be set to "Anyone with the link can view".
